# Contributing to MTN MoMo SDK

Thank you for your interest in contributing to the MTN MoMo SDK!

## Getting Started

1. Fork the repository.
2. Clone your fork: `git clone https://github.com/chabid19/mtn-momo-nodejs.git`
3. Install dependencies: `npm install`

## Development

- Run tests: `npm test`
- Lint code: `npm run lint`
- Format code: `npm run format`

## Pull Requests

1. Create a new branch for your feature or fix.
2. Ensure all tests pass and coverage is maintained.
3. Submit a Pull Request with a clear description of your changes.

## Coding Standards

- We use TypeScript.
- Follow the existing code style (Prettier/ESLint).
- Write tests for new features.
